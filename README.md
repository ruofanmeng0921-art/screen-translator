# 屏幕翻译 · Screen Translator

轻巧的 macOS 英文翻中文工具：点击银色悬浮图标开始，把中文显示在英文原文位置。
Vision 识别和 Apple Translation 翻译在本机完成，无需 API 密钥。

**当前版本 1.5，支持 Apple Silicon（M 系列芯片）Mac、macOS 26.0 及以上。**
Windows、Linux 和 Intel Mac 暂未支持。

## 下载与安装

从 [1.5 下载页面](https://github.com/ruofanmeng0921-art/screen-translator/releases/tag/v1.5) 下载 `ScreenTranslator-1.5-macOS-arm64.dmg`，打开后把
「屏幕翻译.app」拖入「应用程序」。也可以下载 ZIP，解压后移动应用。

此版本使用固定的本地开发证书签名，**尚未进行 Apple Developer ID 公证**。
首次打开可能被 macOS 拦截：先尝试打开，再到「系统设置 → 隐私与安全性」
点击「仍要打开」，完成系统验证。操作方式见
[Apple 官方说明](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)。
无需关闭系统安全保护，也不需要信任额外的根证书。

## 使用

1. 打开应用，点击屏幕边缘的银色图标。
2. 系统要求选屏时，选择要翻译的完整屏幕并确认共享。这里只授权本机读取画面，
   不会向别人传输屏幕。
3. 首次使用按提示下载英文和简体中文语言包，之后翻译可离线进行。
4. 点击暂停，再次点击恢复。本次运行中沿用选屏；退出后可能需要重新选择。

| 操作 | 效果 |
| --- | --- |
| 点击开启 | 立即放大 3 倍，准备时快速明暗变化，运行时缓慢呼吸 |
| 点击暂停 | 收缩并停止呼吸 |
| 鼠标悬停 | 暂停时也可放大 3 倍，移出恢复 |
| 拖动 | 移动悬浮窗，拖动期间隐藏旧译文 |
| 右键／菜单栏 | 恢复原文、切换屏幕、下载语言包、退出 |

常态图形约 16 × 19 点。覆盖层不接收鼠标事件，可以继续操作下面的页面。
重复启动不会创建第二个悬浮图标。

## 隐私与翻译规则

- ScreenCaptureKit 读取屏幕，Vision 两轮复核英文，Apple Translation 本地翻译。
- 截图仅在内存中处理，不保存到磁盘，不录制音频；没有自建服务器、账号或遥测。
- 图标和翻译覆盖层排除在捕获输入之外；滚动、点击、拖动时清除过时译文。
- 保留软件名称、技术缩写、代码名称和词库不认识的词。保护词被修改或遗漏时
  保留整行原文。这是保守规则，不能保证所有专业含义都能被正确判断。

## 限制与排查

- 每轮识别间隔约 0.9 秒，首次翻译大量文字时可能更慢。
- 小字、复杂背景、置信度不足、两轮识别不一致时保留原文，中英文混排暂时不翻译。
- 中文较长时会缩小或省略。系统保护的画面可能无法捕获。
- 新增显示器后暂停再开始；右键「选择翻译屏幕…」可更换屏幕。
- 暂无开机自动启动、自动更新功能。
- 反复出现权限弹窗时，确认已将应用移入「应用程序」，退出后重开，使用系统选屏。
  请勿修改系统 TCC 数据库。
- 缺少语言包时，右键「准备翻译语言包…」。

## 从源码构建

需要 Apple Silicon Mac、macOS 26+、包含 macOS 26 SDK 的 Xcode 或 Command Line Tools，
以及 Python 3。在仓库目录运行：

```sh
zsh build.sh
".build/屏幕翻译.app/Contents/MacOS/ScreenTranslator" --self-test
```

应用生成在 `.build/屏幕翻译.app`。没有私有签名目录时默认使用 ad-hoc 签名，
无需开发者账号；重新编译后可能需要重新授权屏幕访问。
自测使用合成图片，不读取实际屏幕；语言包未安装时会报告翻译测试待完成。

维护者保留原始 `.signing/` 时，默认构建或 `zsh build.sh --signing local`
继续使用固定证书、应用标识和指定签名要求。身份丢失或证书改变时会停止，
绝不会悄悄生成新证书。私钥、加密身份文件和密码不得提交或分享；仓库只保留公开指纹。

```sh
zsh Tools/PackageRelease.sh
```

ZIP、DMG 和 SHA-256 校验文件生成于 `dist/`。见 [发布说明](RELEASE_NOTES.md)
和 [更新记录](CHANGELOG.md)。
